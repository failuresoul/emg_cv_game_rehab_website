# Day 19

**Validation and documentation: tools one person can use alone, an analysis pipeline that never invents a number, and the documents for the thesis.**

## What was built

- **Task 1: validation tools and pipeline.**
  - **Development pages:**
    - `/dev/latency`: stage timings, a square that flips when the wrist crosses a line, and a CSV;
    - `/dev/angle-validation`: a 5 s countdown, 2 s of averaged MediaPipe 3D and 2D angles, the clinometer's reading typed in, and a CSV.
  - **Repeatability visits:** the admin marks the next session as visit 1–3. The visit is the camera check, calibration and the six warm-up exercises with the standard targets, then it ends. The admin can export the visits as CSV.
  - **`analysis/validation/`:**
    - `rep_accuracy.py`, which uses the app's own counters through a Node exporter;
    - `stats.py`, with worked-example tests (including the Shrout and Fleiss ICC);
    - `run_validation.py`, where missing data is PENDING. It records provenance, writes figures at 300 dpi as PNG and SVG, and writes `mdc.json`. `--demo` goes to a separate, labelled folder.
- **Task 2: measured MDCs and documents.**
  - **`app/core/mdc.py`:**
    - it uses the measured MDCs (real data only, with provenance) and refuses unusable values with a reason;
    - the admin badge reads "measured (n=1, pilot)" or "provisional";
    - `backfill_metrics.py` reports the statuses.
  - **Documents:**
    - `validation.md` and `results-summary.md` (generated by `render_docs.py`);
    - `architecture.md` (Mermaid);
    - `data-dictionary.md` (generated from the code);
    - `methods-draft.md`, with `[TODO]`s and references to verify;
    - the README docs index.
- **Task 3: this review.** See the results below.

## Finding: repetition counting when seated

Played through the warm-up's counters, `shadik_full.json` (right side) counted 7 of 28 scripted repetitions:

- **Shoulder flexion and abduction (0 of 3 each):** the seated arm never went below 45° and 68°. A repetition needs the arm back below the 30° rest line.
- **Elbow and hand:** they only just reached their targets.
- **Thumb opposition:** no full round was counted.

The thresholds were left unchanged. Deciding them is check 3 in `pending-manual-checks.md`, after the validation session.

## Decisions

- **Demo data is kept apart:** only the demo folder holds it, labelled, and the app and the documents never read it.
- **Documents with numbers are generated from the result files:** the only numbers written by hand are thresholds and constants from the code.
- **MDCs from one person are labelled "measured (n=1, pilot)":** ICC is "not applicable (n=1)".
