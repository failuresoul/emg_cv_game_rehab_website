# MuVi Rehab ১.০ ইনস্টল করা (সংক্ষেপে)

পুরো নির্দেশনা ইংরেজিতে আছে: [install.md](install.md)। এটি একটি গবেষণা প্রোটোটাইপ, চিকিৎসা যন্ত্র নয়।

## যা লাগবে

- **কম্পিউটার:** ওয়েবক্যামসহ Windows 10/11 কম্পিউটার, ৮ জিবি র‍্যাম (ভাষা মডেলসহ ১৬ জিবি)।
- **ব্রাউজার:** Chrome বা Edge। পেশি সেন্সরের জন্য Web Serial শুধু এগুলোতে চলে।
- **ঠিকানা:** অ্যাপটি `http://localhost:8080` ঠিকানায় খুলুন। ক্যামেরা ও সেন্সর শুধু নিরাপদ ঠিকানায় চলে, আর localhost নিরাপদ ধরা হয়।

## ধাপগুলো

1. `server\.env.example` ফাইলটি `server\.env` নামে কপি করুন। তারপর অ্যাডমিনের ইমেইল, অন্তত ১২ অক্ষরের পাসওয়ার্ড এবং একটি লম্বা এলোমেলো `JWT_SECRET` লিখুন।
2. Docker Desktop ইনস্টল করুন। তারপর PowerShell-এ চালান:

   ```powershell
   .\scripts\start.ps1 -Model ollama
   ```

   - **GPU থাকলে:** `-Model gpu` দিন।
   - **মডেল ছাড়া চালাতে:** `server\.env`-এ `LLM_PROVIDER=mock` লিখুন। তখন রিপোর্ট টেমপ্লেট থেকে আসবে।

3. ব্রাউজারে `http://localhost:8080` খুলে অ্যাডমিন হিসেবে লগ ইন করুন।
4. বন্ধ করতে চালান `.\scripts\stop.ps1`। তথ্য মুছে যায় না।

## ব্যাকআপ

`.\scripts\backup.ps1` চালালে ডাটাবেসের একটি কপি `backups\` ফোল্ডারে জমা হয়।

## সমস্যা হলে

- **ক্যামেরা চলছে না:** ঠিকানার পাশের তালা চিহ্ন থেকে ক্যামেরার অনুমতি দিন।
- **রিপোর্ট সবসময় টেমপ্লেট থেকে আসছে:** দেখুন Ollama চলছে কি না।
- **বাকি সমস্যা:** [install.md](install.md#troubleshooting)-এর টেবিল দেখুন।
